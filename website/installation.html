Installation

Install RelPyDB

RelPyDB is installed directly from GitHub. PyPI publication is planned for a future release.

Requirements: a C compiler

RelPyDB runs on a native C engine, so a C compiler and the Python development headers are required at install time. This is not optional — if the engine cannot be built, import relpy fails with a clear instruction to build it.

PlatformInstall the toolchain
macOSxcode-select --install (installs clang); use Python from Homebrew or python.org
Debian / Ubuntusudo apt-get install build-essential python3-dev
Fedora / RHELsudo dnf install gcc python3-devel
WindowsInstall the “Microsoft C++ Build Tools”

Verify the C engine is active

Run this from a directory other than the source checkout — otherwise Python imports the local relpy/ folder, which has no compiled extension:

python -c "import relpy, os; \
print('C extensions:', [f for f in os.listdir(os.path.dirname(relpy.__file__)) if f.endswith('.so')])"

You should see two files: _relpy_core... and _relpyengine.... If import relpy raises “C engine is not built”, you are either running from the source directory (leave it) or the build was skipped (install a C compiler and reinstall).

Install from GitHub

Use pip with the repository URL:

python -m pip install git+https://github.com/mandelreouven2002/RelPyDB.git
Note: If you use a virtual environment, activate it before running this command.

Install into a virtual environment

Best practice for any Python project:

# Create and activate a virtual environment
python -m venv .venv
source .venv/bin/activate   # macOS / Linux
.venv\Scripts\activate     # Windows

# Install RelPyDB
pip install git+https://github.com/mandelreouven2002/RelPyDB.git

Verify the installation

Run this one-liner to confirm RelPyDB imported correctly:

python -c "from relpy import RelPy; db = RelPy(); print('RelPyDB ready')"
Expected output
RelPyDB ready

Optional dependencies

RelPyDB's core has no required dependencies beyond the Python standard library. Some export functions require optional packages:

FeaturePackageInstall
to_pandaspandaspip install pandas
to_numpynumpypip install numpy
Encrypted columnscryptographypip install cryptography

Calling an export function without its package raises a descriptive ImportError.

Database backends (optional)

The core library needs nothing beyond the standard library. To mirror a database to a real SQL engine (see Databases and Backends), install the extra for your target — each pulls in SQLAlchemy and the right driver:

TargetInstall
PostgreSQLpip install "relpy[postgres]"
MySQL / MariaDBpip install "relpy[mysql]"
Oraclepip install "relpy[oracle]"
Azure SQL / SQL Serverpip install "relpy[azure]"
Everythingpip install "relpy[all]"

SQLite needs no driver (it ships with Python). The server and remote client are part of the core — no extra install required.
